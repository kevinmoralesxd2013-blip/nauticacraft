# NauticaCraft

Hosting de servidores de Minecraft.

Página de presentación con panel de control demo (consola, Start/Stop/Restart, RAM/CPU, plugins, login).

## Ver la página

Abre el archivo `index.html` en tu navegador, o activa GitHub Pages:

1. Ve a **Settings → Pages**
2. Source: Deploy from a branch
3. Branch: `main` / root
4. Guarda

En unos minutos estará en:
**https://kevinmoralesxd2013-blip.github.io/nauticacraft/**
